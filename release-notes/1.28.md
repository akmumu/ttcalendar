# 抬头日历 1.28

- 自定义日期读取失败时显示具体错误和“重新读取”按钮，不再误显示为“还没有自定义日期”。
- 读取失败或数据格式异常时，阻止增删改覆盖原有记录；保存失败时保留编辑内容并显示原因。
- 无法读取日期时保留已经安排的通知，避免把读取失败当成删除全部日期。
- 自定义日期修改后同步更新侧栏与“管理全部”；切回应用时重新读取列表。
- 迁移旧数据时不把无法读取的目标文件当成不存在，避免错误覆盖。

如果小组件仍显示日期、主应用却无法读取，本版会显示实际错误，方便进一步排查。此更新不代表已经修复所有系统访问权限问题，也不会从小组件缓存恢复数据。

macOS 14.0 或更高版本，支持 Apple Silicon 和 Intel。沿用现有 ad-hoc 签名分发，未进行 Developer ID 公证。

1.22 及以后版本可以在应用内“检查更新”。1.21 及更早版本因历史更新密钥轮换，需要手动安装一次新版。
