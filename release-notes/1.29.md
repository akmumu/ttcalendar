# 抬头日历 1.29

- 主应用和小组件增加“重启小组件”入口，结束抬头日历自身的小组件进程并请求系统重新加载，保留自定义日期。
- 设置中增加“重启系统小组件服务”备用入口；确认后会短暂重载所有桌面小组件与通知中心，适用于系统宿主卡住的情况。
- 增加自动检查更新开关。主应用通过 Sparkle 检查，小组件也会在系统允许刷新时检查更新源，检查间隔至少六小时。
- 发现新版本时，主应用显示版本提示、Dock 显示“新”，小组件顶部显示橙色下载标记，点击可打开应用检查更新。
- 跳过某个版本后隐藏该版本标记；更新到新版后自动清除旧标记，离线时保留已有检查结果。

小组件的显示与刷新由 macOS 调度；卡住时请从主应用侧栏使用“重启小组件”。更新标记不保证实时出现。

macOS 14.0 或更高版本，支持 Apple Silicon 和 Intel。沿用现有 ad-hoc 签名分发，未进行 Developer ID 公证。

1.22 及以后版本可以在应用内“检查更新”。1.21 及更早版本需手动安装一次新版。
