# 抬头日历 1.25

- 新增自定义日期通知提醒，默认关闭，支持当天或提前 1、3、7 天及自定义时间。
- 提前提醒可同时保留当天提醒；授权后无需保持应用运行。
- 编辑、关闭提醒或删除日期时同步更新通知，并提供权限和失败提示。
- 正确处理跨年及闰日提醒，修复非闰年编辑 2 月 29 日生日时日期变化的问题。

使用方式：添加或编辑特殊日期，滚动到“提醒”，开启“通知提醒”后保存。普通年度日期自动重复；闰日相关提醒预排未来 8 年，打开应用时续排。通知展示受 macOS 通知设置和专注模式影响。

macOS 14.0 或更高版本，支持 Apple Silicon 和 Intel。安装包沿用现有 ad-hoc 分发方式，未进行 Developer ID 公证。

1.22 及以后版本可以在应用内“检查更新”。1.21 及更早版本因历史更新密钥轮换，需要手动安装一次新版。
